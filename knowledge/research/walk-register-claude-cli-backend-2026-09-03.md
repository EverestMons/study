## Walk 0 — context pin (REAL, measured 2026-09-03)

**CEO directive (verbatim intent):** make the study app "a `claude -p` setup so that i can use it locally myself without being tied to the api." The operative words are *locally myself* — read as an opt-in local backend for the CEO's own machine, not a replacement of the API path for anyone else. That reading is routed into the diagnostic as **Fork 1**, to be confirmed rather than assumed.

Every line below is a Planner CLAIM measured at current HEAD (`a87df1e`); the diagnostic agent re-reads each and corrects it if wrong.

1. **Single egress.** `https://api.anthropic.com/v1/messages` appears in exactly three places, all in `src/lib/api.js` (:45, :89, :184) — inside `callClaude` (:39), `callClaudeStream` (:80), `testApiKey` (:181). No other file in `src/` reaches the model. The backend swap therefore has a **two-function seam**, not a codebase-wide one.
2. **Call-site census (12, across 7 files).** `StudyContext.jsx:1234`, `:1314` (both `callClaudeStream`); `components/study/SkillsPanel.jsx:192`; `lib/conceptLinks.js:122`, `:210`; `lib/syllabusParser.js:191`; `lib/skills.js:254`, `:337`; `lib/extraction.js:852`, `:926`, `:1364`; `lib/study.js:2019`, `:2074`. Every `callClaude` site passes a **single-element** `messages` array; only `StudyContext.jsx:1314` passes a multi-turn history (`chatMsgs`).
3. **No concurrency to preserve.** No `Promise.all`/`allSettled` wraps any model call in `extraction.js`, `skills.js`, `study.js`, or `conceptLinks.js`; the sole `Promise.all` in those files is `skills.js:619` over content-hash checks. Model calls are **sequential**, so a slower per-call backend degrades wall-clock linearly and cannot deadlock on a spawn pool.
4. **Model pinning.** `MODEL_SONNET = "claude-sonnet-4-20250514"` (api.js:22), `MODEL_HAIKU = "claude-haiku-4-5-20251001"` (:23); the `useHaiku` boolean is the only model selector callers have. `callClaudeStream` **hardcodes** `"claude-sonnet-4-20250514"` inline at :98 rather than reading the constant — a pre-existing inconsistency the backend work will have to resolve one way or the other.
5. **Tauri surface.** `src-tauri/capabilities/default.json` already grants `shell:allow-open` plus a `shell:allow-execute` scoped to **two fixed cmd strings** (`soffice`, `/Applications/LibreOffice.app/Contents/MacOS/soffice`) with `args: true`, and an `http:default` scoped to `https://api.anthropic.com/**`. `tauri-plugin-shell = "2"` is in `src-tauri/Cargo.toml:17` and initialised at `src-tauri/src/lib.rs:81`. `lib.rs` registers exactly **one** `#[tauri::command]` (`greet`, :5, handler :91). The fixed-cmd shape of the existing scope entries is the reason Q3 must decide between shell-plugin scoping and a Rust command.
6. **CLI probe — run on this machine 2026-09-03, `claude` 2.1.178 at `/opt/homebrew/bin/claude`:**
   - `echo "Reply with only the word PONG." | claude -p --tools "" --model sonnet --output-format json` → one JSON object; `result` = `"PONG"`, `is_error` false, `stop_reason` `"end_turn"`, `session_id` present, `duration_ms` **2515**, wall **7.58s**, `usage.cache_creation_input_tokens` **15015**.
   - Same call plus `--system-prompt "You are a terse assistant." --disable-slash-commands` → `result` `"PONG"`, `duration_ms` **4023**, `cache_creation_input_tokens` **9092**.
   - **The pin that matters:** a fixed per-call input overhead of roughly **9k–15k tokens survives `--tools ""`**. The direct API path carries none of it. On a subscription this is rate-limit consumption rather than dollars, which is exactly why Q6 measures it rather than pricing it.
7. **`--bare` is disqualified, by its own help text.** It states Anthropic auth is strictly `ANTHROPIC_API_KEY` or `apiKeyHelper` and that "OAuth and keychain are never read." The one flag that would strip the overhead is the one mode that cannot satisfy "without being tied to the api." This makes Q7 (auth mode) the load-bearing question of the whole request, not a detail.
8. **Flags available at 2.1.178** (from `claude --help`): `-p/--print`, `--output-format text|json|stream-json`, `--include-partial-messages` (stream-json only), `--input-format text|stream-json`, `--system-prompt`, `--append-system-prompt`, `--model` (alias or full id), `--tools` (`""` disables all), `--session-id`, `-r/--resume`, `--json-schema`, `--max-budget-usd`, `--no-session-persistence`, `--disable-slash-commands`, `--settings`, `--strict-mcp-config`.
9. **Prior art in-repo:** `docs/planning/python-sidecar-spec.md` already establishes the sidecar-via-`tauri-plugin-shell` pattern for the PDF parser (short-lived process, JSON on stdout, exit). Q3 must say whether the CLI backend is that same pattern or a different one — the difference is that the sidecar is *bundled* and `claude` is *not*.
10. **Nothing in `knowledge/` addresses this.** Grep over `knowledge/` and `docs/` for `claude -p` / `--print` / subscription / "without api key" returns only `docs/buzz-macos-install-guide.md` and the sidecar spec — no prior diagnostic answers any question below.
